# Главная — первый отдельный раунд телефона

Статус: **предложение для просмотра**, не принятый экран. 2026-11-13.
После общего Dream владелец предложил подробный разбор экранов по Android-спеке.
Этот раунд начинает этап 3; библиотека, артист и другие разделы пока остаются
контекстом переходов. Следующий перенос в Compose следует отдельной приёмке экрана.

## Что перенесено из WEB

- Шапка, фраза настроения, сфера «Поток» и «Настроить волну».
- Поиск с переключением «Библиотека / ИИ» и перемещающейся подсветкой.
  Библиотека открывает поиск по четырём песням снимка, ИИ — ассистента с фокусом ввода.
- Два вайба стопками обложек, строка фонотеки с веером, три альбома, неделя.
- На компактном экране неделя сохраняет заголовок и столбики, подробные числа убраны,
  как допускает WEB-правило короткой главной. Альбомы остаются квадратными.
- Сфера использует четыре траектории и периоды `web/src/ui/Orb.tsx`, общую форму
  материала и однократный отклик. Скрытая сфера останавливается; reduced motion
  оставляет статическую форму. Погодный фон здесь только спокойное цветовое поле.

## Границы этого раунда

Это первая телефонная композиция для обсуждения пропорций и входов. Живая погода,
полная логика фраз и вайбов, детали панели «Настроить волну», длинная история недели
и реальный поиск/состояние аккаунта ещё требуют отдельной проработки главной.
Четыре альбома и их метаданные — из снимка библиотеки. Числа недели, ответы и
действия — сценарии макета, явно обозначенные вне экрана приложения. Аудио не встроено.

## Что разбирать дальше

1. Баланс шапки, заголовка и сферы на трёх размерах; достаточно ли воздуха на 360 px.
2. Порядок вайбов, поиска, фонотеки и альбомов; понятность переключения «Библиотека / ИИ».
3. Входы/возвраты, состояния загрузки, пустой библиотеки, ошибки, отсутствия сети и длинных названий.
4. Небо, детальные шиты и реакция сферы; затем зафиксировать принятый телефонный эталон.
5. Перенос главной в Compose с проверками этапа; следующий экран по спеке — библиотека.
