# Главная — предложение первого раунда

2026-11-13. **Предложение для просмотра, ещё не принятый телефонный экран.**
Запрос владельца: «теперь предложи главный экран, следуй спеке и общему обновленному
дизайн коду». Один вариант композиции, две темы. Основа — принятая WEB-главная,
а не новый каталог карточек. Библиотека, артист, импорт и полный альбом пока служат
контекстом переходов; их подробные раунды идут по отдельным этапам.

Один автономный HTML со шрифтами, обложками и кодом. На компьютере сбоку — размеры
360×780, 412×915, 448×998. На телефоне макет занимает его окно; панель просмотра ниже.
По умолчанию время берётся из часов устройства, погода — сценарий «ясно».
Панель позволяет выбрать время, погоду, тему, состояние главной и Потока.

## Предлагаемая композиция

1. **Шапка**: MusiX и тихая кнопка настроек без плашки.
2. **Твой вайб**: фраза в две строки, известные имена ведут к артистам. Ниже — сфера
   «Потока» и «Настроить волну». Запуск/пауза остаются на главной; плеер открывает мини-плеер.
3. **Вайбы**: две стопки обложек. Нажатие запускает подборку, её верхняя обложка летит
   в мини-плеер; подписи не двигаются вместе с ней.
4. **Поиск**: одна стеклянная строка с «Библиотека / ИИ». Следом — фонотека, счётчики
   и веер обложек. Поиск по фонотеке — режим по умолчанию.
5. **Поставить альбом**: три обложки в одном ряду, название, артист и причина «≈ вайб».
   Пластинка выглядывает вверх-влево при наведении/нажатии, внутри полей своего блока.
6. **Неделя**: одна сумма и семь столбиков. Палец/курсор выбирает день, число меняется
   на том же месте. Нажатие на подпись открывает подробности.

На 360×780 сохраняется весь экран без прокрутки: сфера и обложки становятся меньше,
причины альбомов и подписи дней уходят из основного вида. Причина остаётся в шите
альбома, дни — в подробностях недели. На больших размерах добавляется воздух.
Плеер и навигация сохраняют ранее показанную компоновку и физику.

## Взаимодействия и состояния

- **Поток**: до запуска, загрузка, играет, пауза, ошибка → повтор. Нажатие даёт сфере
  податливость, движение жидкости, однократный ореол и ускорение кольца без смены фазы.
- **Настройка волны**: на телефоне предложен шит вместо разворачивания блока внутри
  WEB-главной — так основной экран сохраняет свою высоту. Четыре настоящих пресета:
  «Микс», «Любимое», «Давно не слушал», «Незнакомое»; «Спокойное» / «Бодрое» можно снять.
  Выбор сохраняется локально в отдельном ключе макета и меняет скорость капель сферы.
- **FluidHighlight**: принятая механика из витрины — подсветка следует пальцу,
  выбор фиксируется при отпускании, отмена возвращает прежнее значение; есть клавиатура.
  В настройке четыре сегмента разной ширины, чтобы длинные русские подписи помещались в 13 px.
- **Поиск**: шит с артистами, альбомами и песнями, выделение совпадения, очистка,
  отсутствие результатов, Enter, вход «/». Режим ИИ предлагает три примера и передаёт
  введённый текст ассистенту с принятыми Steps/Richbox. Список результатов прокручивается
  внутри шита, сама главная — нет.
- **Неделя**: отдельные дни, нулевой день, четыре дня подряд, восемь первых прослушиваний,
  ведущий жанр. Диаграмма меняет подпись без всплывающего дубликата.
- **Главная**: обычная, загрузка, пустая библиотека, ошибка с повтором, без сети,
  длинные названия, одна песня, длинный счётчик «1000». В пустой библиотеке нет старого
  мини-плеера; в сценарии одной песни он показывает её. Без сети воспроизведение недоступно.
- **Две темы**: главная, её шиты, мини-плеер и навигация. Погодная симуляция сохраняет
  накопленный снег при смене темы. Другие страницы пока остаются общим контекстом Dream.

## Источники и границы

- Композиция: `design/code/screens/home.md`, `design/reference/home/`, Android-спека §5.2, этап 3.
- Небо: палитры и физика из `design/reference/home/logic.js`; цвета осадков светлой темы —
  текущий WEB `ui/Sky.tsx`. В `home-sky.js` изменены координаты под телефон, плотность
  частиц по площади и управление жизненным циклом. Снег накапливается локально в ячейках,
  дождь разбивается о поверхности. Нет общей полосы снега от одной снежинки.
- Сфера: исходные траектории, периоды и отклик `web/src/ui/Orb.tsx`; цвета приглушаются
  той же функцией `dusty` из `web/src/lib/color.ts`. Глянец заново не придумывался.
- Текучая подсветка: `vendor/tactile-showcase.js`, карточка `fluid`; пять файлов `vendor/`
  не менялись. Шрифты и шкала — общий дизайн-код; HTML-стекло — существующий аналог Haze.
- Четыре песни, обложки и метаданные взяты из снимка библиотеки. Фраза, вайбы, причины
  рекомендаций, цифры недели и погода — **сценарии макета**, обозначенные в панели просмотра.
  Алгоритм WEB-рекомендаций не заменялся новой логикой; здесь показан формат его результатов.
  «1000» проверяет только счётчик, поиск работает по четырём настоящим записям.
- Аудио и API не подключены. Сохранение настроек относится только к этому HTML.
  APK остаётся 2.1.1; перенос в Compose следует отдельной приёмке экрана.

## Проверки

`verify-home.mjs`: 48 сочетаний размера/темы/состояния, 16 сочетаний времени и погоды;
запуск, пауза и повтор Потока, сохранение пресетов, поиск и передача вопроса,
перелёт правильной обложки, дни недели, остановка скрытых циклов, локальное накопление
снега, автономное открытие файла и reduced motion. Снимки — `out/checks/home-r1-*.png`,
результаты — `home-r1-results.json`. Регрессии `verify.mjs` и `verify-design.mjs` также проходят.

Проверка выполнена в Chrome на CPU. Реальная клавиатура, вибрация и бюджет кадров
Pixel проверяются на этапе APK. В видимой главной небо и сфера живые, как в WEB;
под шитом, за плеером, на другой странице и в скрытой вкладке их циклы останавливаются.
При reduced motion остаётся статический кадр.

Для следующего обсуждения: масштаб сферы и фразы, плотность компактного экрана,
перенос настройки волны в шит и объём недели. Это предложения, не уже принятые правила телефона.
