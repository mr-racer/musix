# Dream v1 — сохранённый черновой ориентир

По уточнению владельца 2026-11-13 первоначальный Dream остаётся «более сырой,
но +- норм версией». Общая идея подходит; это не окончательная приёмка всех экранов.
Текущая полировка и отдельные раунды экранов продолжаются рядом с ним.

- [Открыть исходный HTML](http://100.65.53.57:8765/android-dream-v1.html).
- Локально: `/mnt/data/android-rebuild/design/proposals/android-2026-11-13/out/android-dream-v1.html`.
- Исходники: коммит `877c233f131d0c5634848f58d8fc94ddbbd3be4f`, до текущего прохода типографики и Steps.
- SHA-256: `f6f58f46a000bb2f9d1d0ab7b5449ceee67e92809a93e6edc852b30743cb0ef3`.
- [Манифест](manifest.json) записан в git; HTML с изображениями библиотеки находится
  в локальном `out/`, как остальные артефакты снимка.

Файл скопирован побайтно до новых правок. `build.py` не записывает в него;
`verify-design.mjs` проверяет его SHA-256. Исходные компоненты витрины также
сохраняются отдельно в `vendor/` с собственными контрольными суммами.

Актуальное предложение: `out/android-review.html`. Следующий отдельный раунд:
[главная](../home-review/README.md). В этот исходный Dream не переносятся новые правки.
