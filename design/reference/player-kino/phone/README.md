# «Кино» на телефоне — общая компоновка и дальнейшая полировка

2026-11-13 владелец после просмотра: «В целом мне нравится, глобально вариант
хороший, надо дополишнуть». Базовый HTML — коммит `3401f1b`, каркас и плеер вместе.
Запрошенные уточнения: непрерывная волна, плавное завершение next/previous,
Haze / haze-glass, play/pause только на обложке с первой подсказкой, мягкая
пружина с большей телесностью. Они записаны в §6.4–6.5 Android-спеки.

Последующее уточнение владельца: первоначальный Dream сохранить как более сырой,
но в целом подходящий ориентир; затем подробно разбирать каждый экран по спеке.
Это уточняет границы раннего одобрения: общий замысел подходит, окончательная
типографика, состояния и каждый экран принимаются отдельно.
