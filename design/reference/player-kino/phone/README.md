# «Кино» на телефоне — принятая компоновка

2026-11-13 владелец после просмотра: «В целом мне нравится, глобально вариант
хороший, надо дополишнуть». Базовый HTML — коммит `3401f1b`, каркас и плеер вместе.

Haze / haze-glass, play/pause только на обложке с первой подсказкой, мягкая
пружина с большей телесностью. Они записаны в §6.4–6.5 Android-спеки.
